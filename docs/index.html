9Drive

Pool de contas Google Drive do PCM Lab (UEPB) — vários Drives, um painel só.

9Drive é uma aplicação de uso interno do PCM Lab — Laboratório de Pesquisa em Química de Materiais, Universidade Estadual da Paraíba (UEPB). Ela reúne as contas Google Drive do laboratório em um único painel e direciona cada arquivo enviado para a conta que tem mais espaço livre, permitindo aproveitar a cota somada das contas em vez de uma única cota.

O que a aplicação faz

  • Autoriza, com consentimento explícito do titular, acesso ao Google Drive de cada conta conectada;
  • Envia arquivos (upload) pela conta com mais espaço disponível, de forma automática;
  • Lista, organiza em pastas virtuais, compartilha e exclui os arquivos enviados;
  • Exibe o uso de cota de cada conta conectada.
Uso dos dados do Google

O uso das informações recebidas das APIs do Google pelo 9Drive está em conformidade com a Política de Dados de Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use).
